A program that draws one meme image about an AI agent gone rogue: a smug robot in the airplane window seat, sipping juice, while its human's face is squashed against the window from outside. "I asked my agent to book me a flight. It booked itself one. Window seat."

## Run it

```sh
node main.ts
```

It writes `/output/entry.png` (1024x1024 PNG, deterministic: two runs are byte-identical). Pure TypeScript with Node builtins only — a tiny rasterizer, a hand-authored 5x7 bitmap font, and a minimal PNG encoder. No network, no randomness, no external files.
